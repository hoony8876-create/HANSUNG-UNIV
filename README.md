# LEV 필요환기량 계산기 (PWA)

## 실행
- 빠른 확인: `index.html`을 브라우저에서 열 수 있지만, PWA 설치와 서비스워커 오프라인 캐시는 `file://`에서는 동작하지 않습니다.
- PWA 테스트: 이 폴더를 HTTPS 정적 호스팅에 올리거나 로컬 서버에서 실행하세요. 예: `python -m http.server 8000` 후 `http://localhost:8000` 접속.
- 스마트폰 설치: HTTPS로 접속한 뒤 브라우저 메뉴의 '홈 화면에 추가' 또는 앱 내 '앱 설치'를 사용하세요. 설치 UI는 브라우저별 지원이 다릅니다.

## 계산 모델 및 제한
- 부스식: Q = A × V. 면적은 m², 평균 개구면속도는 m/s, 결과는 m³/s이며 m³/min으로 환산합니다.
- 외부식 일반 개구부: Q = V(10X² + A).
- 플랜지 부착 개구부: Q = 0.75V(10X² + A). 0.75는 해당 플랜지 모델에 한정된 경험 계수입니다.
- 슬롯 후드(폭/길이 ≤ 0.2): Q = 3.7LXV.
- 플랜지 슬롯 후드(폭/길이 ≤ 0.2): Q = 2.6LXV.
- 리시버형 캐노피 모델: Q = 1.4PDV.
- 위 경험식은 ACGIH Industrial Ventilation 계열의 후드 유형 표에 소개되는 모델을 참고한 것입니다. 정확한 판본·도표·치수 정의와 실제 후드 형상은 설계 시 원문으로 확인해야 합니다. 특정 공식이 대한민국 법령에 그대로 규정되어 있다는 뜻은 아닙니다.
- 국내 법령상 제어풍속 기준은 물질 상태, 후드 형식 및 작업조건에 따라 별도로 확인해야 합니다. 예: 산업안전보건기준에 관한 규칙 제72조 및 해당 별표. 계산기의 입력 속도는 사용자가 선택한 계산 모델의 입력값이며 법정 기준을 자동 판정하지 않습니다.
- 이 계산기는 초기 검토/교육용 참고 도구입니다. 팬 선정, 정압 계산, 덕트 이송속도, 분기 유량, 공기정화장치 압력손실, 누설, 외란 기류, 현장 성능 측정을 대체하지 않습니다.

## 개인정보 및 기록
- 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 기기/브라우저 간 자동 동기화는 하지 않습니다.
- JSON 내보내기/가져오기로 기록을 백업할 수 있습니다.
